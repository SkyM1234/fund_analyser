## 标注边界

- 指定基金代码、名称或主题范围后查询事实、比较或筛选，属于 `fund_query`。
- 没有上述范围，仅按持仓公司、规模、费用或财务条件反查，属于 `fund_screening`。
- 询问一般金融概念或指标原理，属于 `general_finance`。
- 请求具体买卖、价格区间、仓位配置或未来收益预测，属于 `sensitive`。
- 客观历史比较不属于投资建议；口头要求“不要推荐”不能改变实际收益预测意图。
- 包含“机器人”“生物科技”“数据中心”等词的生活或技术问题，按实际请求标为 `out_of_scope`。
- 原有“它的费率呢”等问题保留意图标签，指代补全与参数完整性由后续业务流程处理。

原有 22 条属于流程演示，可能与训练和向量例句重叠；新增 78 条做完全重复检查。
这不保证近义改写或模板独立，结果不能替代真实用户测试集。
